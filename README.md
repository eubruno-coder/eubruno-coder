## 🧭 Como trabalho

1. **Entender:** identificar a necessidade real do usuário ou negócio.
2. **Prototipar:** transformar requisitos em uma interface e fluxo testáveis.

5. **Evoluir:** documentar decisões e preparar o próximo ciclo.
